Table QA & reasoning-trace evaluation

Judge the question, then the model's reasoning

What this is

Each item is a question about a table, with a reference answer. You do two things:

  1. Judge the Q&A pair against the table: is the question clear, answerable from the table, and is the reference answer right?
  2. Score one reasoning trace from a model, from 1 (poor) to 10 (excellent).

Tables come from automatic extraction and can be misaligned (merged cells flattened). If the table is broken, tick the flag so it isn't mistaken for a bad question.
